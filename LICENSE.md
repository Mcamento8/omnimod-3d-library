## What was NOT included, and why

* **No non-commercial (CC-BY-NC) material.** Sites whose default licence is
  non-commercial were excluded entirely — using them in a commercial product is
  a licence violation, not a grey area.
* **No share-alike (CC-BY-SA) material.** Commercially usable but it forces
  derivative works under the same licence, which is a trap for a closed game.
* **No "free" assets with per-file custom terms.** "Free to download" is not the
  same as "free to use commercially".
* **No FBX / GLB / BLEND duplicates.** The consumer pipeline (OmniMod OMNI3D)
  reads Wavefront OBJ + MTL + PNG. Shipping three extra copies of every mesh
  would triple the repository for no benefit.
